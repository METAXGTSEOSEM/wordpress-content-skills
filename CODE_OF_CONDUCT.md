# Code of conduct

## Our commitment

This project is for people who want to improve evidence-based content work. We
expect contributors and participants to be respectful, specific and honest about
what has been tested.

## Expected behavior

- Critique the work, not the person.
- Support claims with evidence or label them as opinion or hypothesis.
- Respect privacy, customer confidentiality and image rights.
- Remove credentials, personal data and unpublished client material before posting.
- Accept correction when the evidence changes.
- Keep discussions focused on the repository's scope.

## Unacceptable behavior

- Harassment, threats, discriminatory language or personal attacks.
- Publishing private messages, customer data, credentials or confidential work.
- Presenting invented experience, results, certifications or customer stories as real.
- Spam, undisclosed promotion or repeated off-topic posting.
- Deliberately bypassing review, security or attribution requirements.

## Scope

This code applies in repository Issues, Discussions, pull requests, reviews and
other project spaces.

## Reporting and enforcement

Report conduct concerns privately to the maintainer through their GitHub profile.
Do not open a public Issue containing private details.

The maintainer may edit or remove content, close a thread, reject a contribution
or restrict participation when behavior violates this code. Enforcement decisions
will be proportionate and documented privately where appropriate.

## Attribution

This is a concise project-specific code of conduct informed by common open-source
community standards; it is not a legal determination.
