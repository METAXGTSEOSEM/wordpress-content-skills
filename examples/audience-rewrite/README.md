# Audience rewrite: training manual vs buyer decision

This is a synthetic before/after example. It uses a generic software-evaluation
topic and does not contain a real company, product, website or customer.

The example shows the same reader and topic written two ways:

| File | What it shows |
| --- | --- |
| `before.md` | A textbook-style opening that defines the category before addressing a decision. |
| `after.md` | A decision-led opening for an operations lead who must recommend a shortlist. |
| `review.md` | The findings that explain why the first version fails and what changed. |

## What to notice

- The revised opening starts with the decision and the cost of getting it wrong,
  not with a definition.
- The technical and process detail is still present, but it follows the reader's
  decision context.
- The CTA asks for the next useful action, not a generic "contact us."
- The rewrite is not shorter for its own sake; it removes material that did not
  help the reader decide.

Use this as a pattern, not as copy for a live page.
